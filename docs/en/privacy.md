## Hosting

This site is published on GitHub Pages. GitHub logs access: "the visitor's IP address is logged and stored for security purposes". We have no influence over this — the logging cannot be switched off, we cannot see it and we cannot control it.

## Legal basis and balancing of interests

The legal basis is Art. 6 (1) (f) GDPR (legitimate interest in running public project documentation). Balanced against it: this site sets no cookies, loads no fonts, images or scripts from third parties and sends no usage data to analytics services — measured on the built output, re-checked before every deploy (DS-01).

## Third-country transfer

GitHub processes data in the USA: adequacy decision (EU) 2023/1795, GitHub's DPF certification, additionally the standard contractual clauses under decision 2021/914.

## Local storage

Two keys in the browser's `localStorage`, both carrying no identifier:

- `starlight-theme`: the chosen colour scheme. Written only once the theme switcher is used — not on the first page load (measured on the built output).
- `starlight-synced-tabs__<key>`: synchronised tab selections. Only created where tabs are used — nowhere on these pages.

There is no cookie banner, because there are no cookies.

## Data subject rights

Access (Art. 15), rectification (Art. 16), erasure (Art. 17), restriction (Art. 18), portability (Art. 20), objection (Art. 21), and the right to lodge a complaint with a supervisory authority.

## Donations

The donation reference on the legal notice page is a plain text link to an external offering — its terms and its privacy policy apply there.
